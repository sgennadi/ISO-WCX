ISO-WCX v0.21.0 Stable: структура образа, проверка WIM, VS2026 C++26 — WCX-плагин Total Commander
==========================================================

Установка без дополнительных программ
--------------------------------------
1. Откройте https://github.com/sgennadi/ISO-WCX/releases/latest .
2. Скачайте ISO-WCX-v0.21.0.zip из Stable Release и откройте этот ZIP
   непосредственно в Total Commander.
3. Согласитесь на установку из pluginst.inf. В каталоге плагина
   должны находиться ISO-WCX.wcx (32-bit) и ISO-WCX.wcx64 (64-bit).
4. Перезапустите Total Commander и откройте образ клавишами Ctrl+PgDn.

Установка Preview в Total Commander без EXE
---------------------------------------------
В GitHub Actions публикуются три ZIP-установщика с pluginst.inf.

Для Total Commander 64-bit:
  артефакт ISO-WCX-Installable-x64-Preview
  архив ISO-WCX-preview-x64.zip
  устанавливается ТОЛЬКО ISO-WCX.wcx64

Для Total Commander 32-bit:
  артефакт ISO-WCX-Installable-Win32-Preview
  архив ISO-WCX-preview-Win32.zip
  устанавливается ТОЛЬКО ISO-WCX.wcx

Если используются обе редакции TC, остаётся совместимый общий
ISO-WCX-Installable-Preview / ISO-WCX-preview.zip с двумя DLL.

Распакуйте внешнюю упаковку артефакта GitHub. Откройте внутренний ZIP
клавишей Enter в Total Commander и подтвердите установку pluginst.inf.
Внутри архива для конкретной разрядности только один WCX,
pluginst.inf и документация. Не требуется отдельный установщик
EXE, CMD или PowerShell.

В pluginst.inf предлагается привязать 23 расширения образов.
Штатный Total Commander может открывать диалог для каждого расширения:
INF не поддерживает их безусловную массовую регистрацию без подтверждений.
Разрядность нужно выбрать при скачивании ZIP: сам INF не отфильтровывает
содержимое архива. ZIP/RAR/7z и пользовательские кнопки не меняются.
Ранее оставшиеся DLL стандартный установщик самостоятельно не удаляет.

Редактирование Preview:
- WIM: добавить, заменить, удалить файлы/папки; удалять индексы, кроме
  последнего. Через WIMGAPI Apply/Capture, долго на больших install.wim.
  Быстрое создание папок через Mount/Commit экспериментально и выключено.
- ISO9660/Joliet: добавление, замена и удаление только для совместимых
  структур, а не произвольное редактирование загрузочного ISO.
- UDF Type-1: ограниченная экспериментальная запись в UDF-only образах.
- ISO/UDF Bridge: только строго проверенные операции над файлами.
- Гибридный загрузочный ISO: удаление файлов — отдельный Draft PR #65.
- ESD/SWM: пока только чтение. Проверяйте запись на копиях образов.

Исправление скорости ZIP в Preview: ISO-WCX больше не предлагает глобальный
поиск архивов по содержимому (WCX PK_CAPS_BY_CONTENT=64) и немедленно
отклоняет ZIP/RAR/7z до разбора образа. Маска WCX в Preview теперь 158,
а в старом Stable v0.21.0 — 222. ZIP остаётся за штатным Total Commander.
Проверка реальной скорости на вашем компьютере всё ещё необходима.

Файлы с расширением `.udf` регистрируются установщиком вместе с `.iso`.
UDF-only образ с расширением `.iso` распознаётся по содержимому.
Это Stable Core: установка и базовые проверенные операции стабильны, но
часть расширенной поддержки UDF/NTFS/ext4 и операций записи остаётся
экспериментальной. Всё чтение поддерживаемых ISO/UDF и виртуальных дисков выполняется
внутри WCX. Не нужны Setup.exe, PowerShell, CMD, libvhdi.dll,
внешний распаковщик, виртуальный привод, драйвер или монтирование.

Экспорт структуры образа (Stable v0.21.0)
--------------------------------------------------------------
Выберите Files > Pack, расширение ISO-WCX и кнопку
Configure... > Export Image Structure... (Экспорт структуры образа...).
Укажите исходный ISO/UDF/WIM/VHD/VHDX и место сохранения TXT-отчёта.
В отчёте: файловая система, дерево файлов/папок, размеры, атрибуты,
расположение данных и, для ISO/UDF, PVD, Joliet, El Torito, UDF
и состояние системной области. Экспортируются только метаданные:
исходный образ не изменяется и содержимое файлов не копируется.
Внешний disc_inspect.exe и отдельные DLL/утилиты не требуются.
**В Stable v0.21.0 эта кнопка есть.** В старом v0.20.0 её нет.

Встроенная проверка обновлений (с v0.19.0, включена в Stable v0.21.0)
----------------------------------------------------------
В Total Commander откройте Files > Pack, выберите расширение,
обрабатываемое ISO-WCX, затем Configure... > Check now.
В этом же окне есть переключатель
«Не проверять обновления автоматически». Настройка сохраняется
в HKCU\\Software\\ISO-WCX\\Updates. Проверка вручную остаётся доступна.
Автоматическая проверка Stable GitHub — не чаще одного раза в сутки,
в фоновом потоке без задержки открытия образов.
ZIP загружается вместе с SHA256SUMS.txt через HTTPS, проверяется SHA-256
штатным Windows BCrypt и открывается в Total Commander для подтверждения
установки. Загруженная WCX не заменяется во время работы; перезапустите
Total Commander после обновления.
Важно: в исходный Stable v0.18.0 updater ещё не включён.
Если после установки новой Preview нет кнопки Configure..., переустановите
ассоциацию WCX: Total Commander может кэшировать старые флаги плагина.

В Stable v0.20.0 добавлена экспериментальная запись FAT12/16/32
в полностью размещённые фиксированные VHDX (логический сектор 512 байт).
Изменения выполняются во временной копии с проверкой CRC32C двух
заголовков, BAT и побайтовой сверкой полного логического диска.
Предел: x64 — 1 ГиБ логического и 2 ГиБ физического размера;
Win32 — 512 МиБ обоих размеров. Требуется место для временных копий.
Sparse/dynamic VHDX, 4K-секторы, снапшоты и не-FAT разделы остаются
только для чтения. В Stable v0.19.0 этой записи ещё не было.

Preview: IMA/IMG/VFD/FLP (дискеты без MBR), а также BIF с FAT,
открываются напрямую. Непрозрачный загрузочный BIF можно извлечь как
boot-image.bin, без записи. В Stable v0.20.0 (Preview) доступны запись
FAT12/16/32, создание, замена и удаление файлов/каталогов с длинными
именами VFAT (русский, иврит, Unicode), уникальные псевдонимы 8.3.
Запись доступна на отдельной FAT-дискете/RAW, а также в выбранном
`partition1/`, `partition2/` разделе FAT образа IMG/RAW или фиксированного
VHD. Предел: 64 ГиБ (x64) или 512 МиБ (Win32). Проверяются FAT,
FSInfo и резервный boot FAT32, запись в адресно отображаемую временную
копию с атомарной заменой после проверки. Для этого нужно свободное
место под полную копию исходного образа. За один раз редактируется один
раздел. С v0.19.0 (Preview) доступна запись в FAT12/16/32 разделы
`partitionN/` чистых динамических VHD v1 (не разностных).
Всё изменение идёт через временный логический диск и копию VHD;
обновляются BAT и bitmap, затем проверяется побайтовое соответствие
перед атомарной заменой оригинала. Предел логического размера —
1 ГиБ (x64) или 512 МиБ (Win32), нужен запас свободного места под
несколько временных копий. Разностные VHD, неподдерживаемые dynamic/4K VHDX, повреждённые и
слишком большие FAT остаются только для чтения.
Эта возможность входит в Stable v0.19.0 как экспериментальный Preview. Stable v0.18.0 включал
запись только FAT12.
IMZ (WinImage): ZIP stored/deflate, один образ до 32 МиБ, проверка CRC32,
чтение и извлечение без распаковки на диск. Запись IMZ отключена.

Для дисков HDD IMG/RAW, фиксированных VHD и базовых VHDX
(fixed/dynamic) доступны разделы MBR/GPT с FAT12/16/32, exFAT
и экспериментальной поддержкой ext2/3/4 и NTFS. Внутри образа
файлы видны как partition1/, partition2/ и т.д. NTFS пока ограничен:
простые каталоги MFT/$I30 и обычные/разреженные несжатые файлы,
без attribute lists, сжатия, шифрования и восстановления журнала.
Запись на виртуальные HDD допускается только для поддерживаемых FAT-разделов в Preview.

Если Total Commander сообщает "File iso.wcx not found!"
---------------------------------------------------------
Путь вида ...\plugins\wcx\ISO\iso.wcx относится к СТАРОМУ
плагину ISO.WCX, а не к ISO-WCX.

1. Откройте Configuration > Options > Packer >
   Configure packer extension WCXs.
2. Выберите расширение iso и удалите ТОЛЬКО старую запись
   с отсутствующим файлом ...\ISO\iso.wcx.
3. Нажмите New type... и укажите новый ISO-WCX\ISO-WCX.wcx.
4. Убедитесь, что рядом находится ISO-WCX.wcx64.
5. Перезапустите Total Commander, проверьте ISO через Ctrl+PgDn.

Плагин не может автоматически исправить ссылку на отсутствующую
DLL до того, как Total Commander его загрузил. Разовая ручная
правка записи не требует отдельной утилиты.

Числа 192 (старые флаги), 222 (Stable v0.21.0) и 158 (новый Preview)
перед запятой в wincmd.ini — флаги возможностей WCX,
это НЕ часть пути к файлу.

Только для Preview: если кнопка Delete в окне ассоциаций WCX не работает,
в установочный ZIP добавлен необязательный скрипт
ISO-WCX-RemoveAssociation.ps1. Выполните в PowerShell
-IniPath "C:\\path\\to\\wincmd.ini" -Extension iso для проверки без записи.
Закройте Total Commander и добавьте -Apply, чтобы удалить только
ассоциацию ISO-WCX с резервной копией INI. Поддерживаются также
RedirectSection в PackerPlugins/PackerPlugins64. Свои кнопки,
команды и другие плагины Total Commander скрипт не удаляет.
ISO-WCX-Repair.ps1 исправляет ссылки на отсутствующий старый ISO.WCX.
Для обычной работы WCX эти скрипты НЕ требуются.

Поддержка ISO9660, Joliet, Rock Ridge, UDF, CUE/BIN, CCD, NRG,
MDS v1 и CSO/ZSO сохраняется. Добавлены встроенные декодеры
ISZ v1 (один файл; нулевые/несжатые/zlib/bzip2 блоки) и DAA 1.00
(один файл, без шифрования, raw DEFLATE).
CHD v5: встроенный статический libchdr, поддержка сжатых CD/DVD,
нескольких дорожек и смешанных дисков с аудио. Дорожки выравниваются
по правилам MAME, ISO/UDF читаются с подходящей дорожки.
Аудиодорожки CHD доступны как CDDA/trackNN.wav (44,1 кГц, стерео,
16 бит). Для дорожек свыше лимита RIFF используется RF64. Родительские
CHD и CD-Text/CD+G не поддерживаются; регистрация .chd по умолчанию
отключена.

Preview: MDS v2/MDF и однофайловый MDX с AES-расшифровкой метаданных
и чтением обычных/сжатых дорожек ISO/UDF. MDX регистрируется установщиком
Preview. Дорожки с паролем (AES-LRW) пока отклоняются.
Пока НЕ поддерживаются: ISZ/DAA с шифрованием, DAA 1.10,
CD-Text/CD+G и родительские CHD, разностный VHD,
разностный VHDX, сложные варианты ext4, NTFS attribute lists,
сжатые/зашифрованные файлы NTFS, восстановление журнала. Кодеки работают
внутри WCX, без внешних EXE, DLL или виртуальных приводов.

Исходники: https://github.com/sgennadi/ISO-WCX

WIM / ESD
---------
Откройте install.wim, boot.wim или поддерживаемый .esd через Ctrl+PgDn.
Внутри будут image1/, image2/ и т.д. Извлечение файлов — F5.
WCX использует системную библиотеку Windows wimgapi.dll; никаких
дополнительных DLL, утилит, драйверов или монтирования не требуется.
Разделённые SWM открываются для просмотра и извлечения при наличии всех
частей в одной папке. Редактирование обычного неразделённого WIM:
добавление, замена и удаление файлов/папок внутри imageN, удаление
индексов кроме последнего. Требуются повышенные Windows-привилегии
backup/restore/security и временное место на NTFS. ESD/SWM только чтение.
Обычные ISO9660/Joliet позволяют ограниченное добавление/замену/удаление,
в том числе экспериментальные имена ISO Long(221) и Joliet Long(110)
(до 110 единиц UTF-16). Такие длины имён не все ISO-программы поддерживают.
Каталог и данные загрузки El Torito BIOS/UEFI сохраняются, а операции с
перекрывающими их файлами отклоняются. ISO/UDF Bridge поддерживает только
замену содержимого существующего файла ТОЧНО того же размера, если ISO и UDF
ссылаются на один общий физический участок. Загрузочные ISO/UDF Bridge,
добавление/удаление файлов, изменение размеров и запись UDF-метаданных пока
не поддерживаются. **UDF-only Type-1** (проверенный негибридный физический раздел,
блоки 2048 байт): атомарное создание нескольких файлов и вложенных
каталогов, ограниченная замена/изменение размера, логическое удаление,
выделение нескольких ShortAD (включая файлы свыше 4 ГиБ) и безопасное
повторное использование освобождённых блоков/FID только при проверенном
единоличном владении. Bitmap/LVID и временная копия проверяются до записи.
Сложные разделы UDF Metadata/VAT/Sparable, создание AED-цепочек,
пересборка ISO/UDF Bridge, ссылки и произвольная разметка не поддерживаются.
Гибридные ISO с системной областью и Rock Ridge не пересобираются.
Результат проверяется отдельно до замены оригинала; используйте копии
важных установочных образов. При извлечении отдельных файлов WIM
альтернативные потоки NTFS и reparse points не восстанавливаются.
