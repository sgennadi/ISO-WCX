ISO-WCX v0.12.1 Preview - исправление старой ассоциации Total Commander
=======================================================================

Ошибка: "File iso.wcx not found!" или "Error, could not load plugin!",
например:
  C:\Program Files\TotalCmd\plugins\wcx\ISO\iso.wcx

Это СТАРЫЙ путь ISO.WCX. Новый ISO-WCX установлен отдельно:
  C:\Program Files\TotalCmd\plugins\wcx\ISO-WCX\ISO-WCX.wcx
  C:\Program Files\TotalCmd\plugins\wcx\ISO-WCX\ISO-WCX.wcx64

Рекомендуемый способ: ISO-WCX-Setup.exe (C++20, x86/x64)
---------------------------------------------------------
1. Откройте ISO-WCX-preview.zip через Total Commander (pluginst.inf),
   либо извлеките весь ZIP целиком.
2. ПОЛНОСТЬЮ закройте все окна Total Commander.
3. Из Windows Explorer запустите ISO-WCX-Setup.exe из каталога плагина
   или из полностью распакованного ZIP.
4. Setup проверяет x86 ISO-WCX.wcx и x64 ISO-WCX.wcx64, при необходимости
   копирует их, находит активный wincmd.ini и RedirectSection, исправляет
   отсутствующий ISO\iso.wcx, устаревшие записи ISO-WCX и неназначенные
   поддерживаемые расширения. Рабочие сторонние плагины не заменяются.
   До изменений создаётся backup INI, обновляется кеш [PackerPlugins64].
5. Снова запустите TC и откройте ISO через Ctrl+PgDn.

Параметры: --dry-run, --ini "C:\path\wincmd.ini", --tc-dir "C:\TotalCmd",
--plugin-dir "D:\TCPlugins\wcx\ISO-WCX", --force-iso, --quiet.
--force-iso принудительно переключает работающий обработчик ISO.
Setup.exe не запускается автоматически из pluginst.inf. Используйте
ту же Windows-учётную запись; ассоциации Windows Explorer не меняются.

Альтернатива: PowerShell/CMD для ремонта только старой iso-записи:
1. Извлеките ZIP целиком (не запускайте BAT внутри открытого ZIP).
2. Запустите ISO-WCX-Repair.cmd. Это проверка БЕЗ изменений.
3. Закройте все окна Total Commander.
4. Запустите ISO-WCX-Repair-Apply.cmd и введите YES.
   Скрипт изменяет ТОЛЬКО старую строку iso=...\\ISO\\iso.wcx
   в активном wincmd.ini. Другие расширения и плагины не затрагиваются.
   Перед изменением создаётся копия .isowcx-backup-YYYYMMDD_HHMMSS.
5. Откройте Total Commander и проверьте ISO через Ctrl+PgDn.

Если скрипт не находит файл настроек, выберите в Total Commander
Configuration > Change Settings Files Directly, узнайте полный путь
wincmd.ini, закройте Total Commander и запустите:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "ISO-WCX-Repair.ps1" -IniPath "C:\\путь\\wincmd.ini" -Apply

Скрипт откажется изменять настройки, если старый iso.wcx ещё
существует, нужный ISO-WCX.wcx64 отсутствует или запущен Total Commander.
Если предпочитаете ручную настройку, используйте инструкцию ниже.

Исправление вручную:
1. Configuration > Options > Packer > Configure packer extension WCXs.
2. Введите расширение iso. В списке Associate with выделите старую
   запись с путем ...\plugins\wcx\ISO\iso.wcx и нажмите Delete.
3. Нажмите New type... и выберите существующий файл
   ...\plugins\wcx\ISO-WCX\ISO-WCX.wcx.
   Для 64-битного Total Commander рядом должен быть ISO-WCX.wcx64.
4. Нажмите OK и перезапустите Total Commander.
5. Откройте ISO клавишами Ctrl+PgDn.

При необходимости проверьте остальные расширения: cue, ccd, nrg,
mds, cso, zso. Меняйте только записи, указывающие на отсутствующий
старый плагин. Не удаляйте ассоциации других работающих плагинов.

Число 192 перед запятой - флаги возможностей WCX, НЕ часть пути.
Не вводите 192 вручную в диалог выбора файла.

pluginst.inf устанавливает новый WCX, но не удаляет старые ассоциации
из wincmd.ini. Не нужно стирать все содержимое wincmd.ini.
Актуальный путь к настройкам: Help > About Total Commander.

Если ошибка остается после исправления пути, проверьте разрядность
Total Commander (x64 должен видеть WCX64) и DLL зависимости.
Файлы Preview не подписаны; проверка в реальном интерфейсе пока
не заменена GitHub Actions.
