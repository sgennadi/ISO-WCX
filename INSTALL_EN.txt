ISO-WCX v0.12.1 Preview - repairing an old Total Commander association
========================================================================

If Total Commander shows "File iso.wcx not found!" or "Error, could
not load plugin!" for ...\plugins\wcx\ISO\iso.wcx, it is attempting to load
the LEGACY ISO.WCX plugin, not this ISO-WCX project.

Recommended: ISO-WCX-Setup.exe (native C++20, x86/x64)
------------------------------------------------------
1. Install the ISO-WCX-preview.zip using Total Commander pluginst.inf,
   or extract the COMPLETE ZIP first.
2. EXIT ALL Total Commander windows.
3. Start ISO-WCX-Setup.exe from the installed plugin folder with
   Windows Explorer (or the fully extracted ZIP folder).
4. Setup validates the x86 WCX and x64 WCX64 pair, copies it if needed,
   finds the active wincmd.ini and redirected sections, repairs missing
   ISO\iso.wcx and stale ISO-WCX paths, and registers unassigned supported
   extensions while preserving working third-party plugins. It backs up
   affected INI files and invalidates the [PackerPlugins64] checksum.
5. Restart Total Commander; open an ISO with Ctrl+PgDn.

Options: --dry-run, --ini "C:\path\wincmd.ini", --tc-dir "C:\TotalCmd",
--plugin-dir "D:\TCPlugins\wcx\ISO-WCX", --force-iso, --quiet.
--force-iso explicitly replaces even a working ISO handler.
Setup does not run automatically from pluginst.inf. Run it only after
closing TC, under the same account. Windows Explorer file associations
are not modified.

Alternative opt-in CMD/PowerShell repair (legacy ISO mapping only):
- Extract the entire ZIP first.
- Run ISO-WCX-Repair.cmd for read-only detection.
- Close ALL Total Commander windows.
- Run ISO-WCX-Repair-Apply.cmd; type YES to approve.
- Only a stale iso=...\\ISO\\iso.wcx entry is changed and a timestamped
  wincmd.ini backup is saved. Other extensions and working plugins remain intact.
- When INI autodetection fails, pass -IniPath "C:\\path\\wincmd.ini" to
  ISO-WCX-Repair.ps1. The script checks that both WCX binaries exist.

Manual alternative:
1. Open Configuration > Options > Packer > Configure packer extension WCXs.
2. Enter extension "iso". Select the OLD entry pointing to
   ...\plugins\wcx\ISO\iso.wcx and press Delete.
3. Click New type... and select the installed
   ...\plugins\wcx\ISO-WCX\ISO-WCX.wcx.
   The corresponding ISO-WCX.wcx64 must be in the same folder for
   64-bit Total Commander, which picks up the sibling DLL automatically.
4. Confirm, restart Total Commander, and open a test ISO with Ctrl+PgDn.

The number 192 in "192,path" is the WCX capability bitfield; it is not
part of the filename and must not be typed into a file picker.

Check extensions cue, ccd, nrg, mds, cso and zso only if they also point
to the missing old DLL. Preserve unrelated working plugin associations.

The pluginst.inf auto-installer installs the new WCX but does not remove
obsolete associations from wincmd.ini. Do not delete all wincmd.ini entries.
The correct INI location is shown in Help > About Total Commander.

If a correctly registered file still will not load, examine Windows
architecture (WCX vs WCX64), DLL dependencies and runtime errors separately.
