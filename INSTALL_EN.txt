ISO-WCX v0.15.0 Preview - standalone Total Commander WCX plugin
================================================================

Installation (no additional tools)
----------------------------------
1. In the GitHub WCX preview workflow, download the combined
   ISO-WCX-Installable-Preview artifact and unzip the outer envelope.
2. Open ISO-WCX-preview.zip in Total Commander. Confirm the plugin
   installation requested by pluginst.inf.
3. Verify the plugin directory contains ISO-WCX.wcx and ISO-WCX.wcx64.
   These are the 32-bit and 64-bit versions of the same WCX plugin.
4. Restart Total Commander and open an ISO, VHD or VHDX with Ctrl+PgDn.

No setup EXE, repair CMD, PowerShell script, external parser DLL, virtual
disk mount, driver, or standalone disk extraction program is necessary.
The WCX binaries include ISO/UDF, supported virtual-disk readers and
native ISZ/DAA optical compressed-stream decoding.

The integrated HDD reader supports MBR/GPT partitions containing FAT12/16/32,
exFAT and experimental subsets of ext2/3/4 in raw IMG/RAW, fixed VHD and
clean base fixed/dynamic VHDX. Files appear under partition1/, etc.
Modern ext4 optional features and NTFS remain unsupported; filesystem
browsing is strictly read-only.

Fixing an old broken ISO.WCX association
----------------------------------------
If Total Commander says "File iso.wcx not found!" pointing to an old
...\plugins\wcx\ISO\iso.wcx, it is using the OLD plugin entry.

1. Open Configuration > Options > Packer > Configure packer extension WCXs.
2. Select extension iso and delete ONLY the obsolete mapping to the missing
   ...\ISO\iso.wcx. Do not delete a working unrelated association.
3. Use New type... and choose the installed ISO-WCX\ISO-WCX.wcx.
4. Keep ISO-WCX.wcx64 beside ISO-WCX.wcx for 64-bit Total Commander.
5. Restart Total Commander and retry Ctrl+PgDn.

A DLL cannot change a missing DLL's association before Total Commander
has loaded it. This is a one-time settings correction, not an
additional required program. The leading "192," sometimes shown in
wincmd.ini is a Total Commander WCX capability mask, NOT part of the
file path. Do not type it in the file selection dialog.

Check other extensions only if they point to that same obsolete plugin.
The installed plugin also handles cue, ccd, nrg, mds v1, cso, zso,
limited single-file isz/daa, partitioned img, raw, vhd and vhdx.

This is PREVIEW software: most formats are read-only. Only plain ISO9660/
Joliet and standard unsplit WIM support restricted editing.
Supported compressed optical subsets:
single-file ISZ v1 (zero/raw/zlib/bzip2) and DAA 1.00 (raw DEFLATE).
CHD v5 supports compressed optical 2048-byte ISO/UDF and experimental
single-track CD Mode 1/Mode 2 Form 1 using statically linked libchdr;
CHD is not registered by default because audio and mixed/multi-track
images remain unsupported.
Not supported: MDS v2/MDX, encrypted/multipart ISZ or DAA, DAA 1.10,
CHD audio/mixed/multi-track/parent chains, dynamic/differencing VHD,
differencing/dirty VHDX, NTFS and advanced unsupported ext4 features.

Source: https://github.com/sgennadi/ISO-WCX

WIM / ESD
---------
Open WIM, compatible ESD or any member of a complete split SWM set with
Ctrl+PgDn. Browse image1/, image2/, etc. and extract with F5.
Unsplit, non-solid standard WIM supports file/directory edits inside an
existing image index and deletion of an index except the last one.
WIM editing needs NTFS staging and elevated Windows backup/restore/security
privileges. ESD and SWM writes are not supported. Plain ISO9660/Joliet
images support restricted, transactional file/folder edits; hybrid,
UDF-bridge and Rock Ridge ISO images remain read-only. Important media
should be edited as copies. System wimgapi.dll runs inside the WCX;
no additional DLL, EXE, mount or driver is required. NTFS alternate
streams and reparse points are not restored by individual-file extraction.
